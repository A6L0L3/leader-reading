## 内容总览

### 领导干部通识知识体系·十三课贯通手册

这是一套把十三部通识著作整合重构成的知识体系，不是十三份摘要的合订本。 / 十三部著作原本各自独立成书，读者逐本读完，得到的往往是十三个互不相干的知识块。本手册做的事是把它们**纵向分成五层、横向打通成网**：每一层回答一类不同的问题，层与层之间可以互相校验、互相支撑。

手册共 **22 个板块**：总览 2 块（学习路径、全景图）、主题 7 块（根基层 / 思维层三块 / 治理层 / 素养层两块，承载十三部书）、用法 13 块（贯通案例、动作清单、场景表、笔记模板、记录细则、问答、辨析、演练、失效边界、验证、误读纠偏、延伸速查、成套方案）。主题板块按"问题同源"合块，用法层的工具全库各一份，不按书重复。

## 库内体例

各文档以「单篇知识库」为通例组织：

1. **`XX系统知识库.md`**——合订本，一篇读完全体系；
2. **`系统知识库/`**——独立 `README.md` 导览（定位、阅读约定、板块索引、使用边界），加板块单篇（板块0 学习路径 → 板块1…N 主题，二级编号形如 `0_1`、`12_3`），可按主题独立查阅；
3. **`读书笔记/`**——所据原典的单本笔记。

各篇普遍遵循同一写法：先给学习路径与认知定位，再讲原理与操作流程，最后落到底层公理、避坑清单、速查附录与验证方法。所据原书（PDF/EPUB 等）不在本仓库内，本仓库仅收录整理笔记与知识库。
