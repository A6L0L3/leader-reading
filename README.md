# 领导干部通识库（**`leader-reading`**）

[![License: CC BY 4.0](https://img.shields.io/badge/License-CC%20BY%204.0-lightgrey.svg)](https://creativecommons.org/licenses/by/4.0/deed.zh)

> 一个把十三部领导干部通识著作整合重构的知识体系。纵向分五层、横向打通成网，以「系统知识库 + 单本读书笔记」双层结构落到**可复述、可迁移、可验证**的学习成果。

本仓库是党政干部通识读物的读书笔记与知识整理，属个人学习研究资料。同一套内容提供三种形态，按需取用。

## README · 导览

### README_1 这是什么，与库内体例

本仓库把十三部通识著作**纵向分成五层、横向打通成网**：根基层（我从哪里来）→ 思维层（我怎么想）→ 治理层（我怎么干）→ 安全层（我怎么防）→ 素养层（我怎么表达、怎么识人）。每篇文档以「单篇知识库」为通例组织，库内体例为：

```
# 板块N · 名称          ← 一级标题，N 取 0~21
## N_x 小节标题          ← 二级标题，x 为该板块内序号（如 0_1、6_27）
```

- 板块编号稳定，跨文件引用一律写「板块N」，配合 `N_x` 小节号可直接定位；
- 每个板块由主旨与结构、方法与工具、案例与落地、校验与纠偏四类内容组成，主题板块末节为收束节（用法 / 动作 / 自查）；
- 并列与对照一律用表格，流程与层级一律用 ASCII 图，不依赖任何外链图片；不写死年份，进度用「第 N 周 / 第 N 天」表述。

## 板块0 · 学习路径和建议

### 0_1 学习路径

1. **先读总览与路径**：读 `新时代领导干部通识读物系统知识库.md` 的 README 与板块0，或 `系统知识库/00_README_总览.md` 与 `00_板块0_学习路径建议.md`，明确五层结构与三种用法。
2. **按五层顺序**：根基 → 思维 → 治理（含安全）→ 素养，逐层建立"从哪来、怎么想、怎么干、怎么表达"。
3. **用法层按需调用**：卡在"取/记/问/辨/练/验/纠/连/用"哪一步，就翻对应用法板块（板块9–21），不是阅读顺序。
4. **回到原典**：每个知识点都能在 `读书笔记/` 找到对应原典笔记，用于溯源与精读。

### 0_2 使用建议与边界声明

- 本仓库为党政干部通识读物的学习笔记与知识整理，仅作为个人学习研究参考，**不代表任何官方立场**，请结合原著与组织安排使用。
- 本仓库全部文件由公开或原始资料收集而来，并经 AI 工具重新归纳、整理与结构化；整体格式与大纲参考了「庚戊学堂」的学习模块组织方式。原始资料、教材与官方文件的著作权归各自权利人所有，本仓库仅对**整理汇编成果**采用 CC BY 4.0（见文末协议）。二创请注明出处，商业使用前请自行确认合规。
