## 内容总览

### 一、系统知识库（22 个板块）

这不是十三份摘要的合订本。十三部著作原本各自独立成书，逐本读完得到的往往是十三个互不相干的知识块；这套体系把它们**纵向分成五层、横向打通成网**，每一层回答一类不同的问题，层与层之间可互相校验。

```text
  第五层  素养层 ── 我怎么表达、怎么识人     写作 · 美学 · 音乐 · 心理学
  第四层  安全层 ── 我怎么防                 中国古代军事
  第三层  治理层 ── 我怎么干                 法治 · 群书治要
  第二层  思维层 ── 我怎么想                 中国哲学 · 马哲 · 马恩经典 · 逻辑学
  第一层  根基层 ── 我从哪里来               中华文化 · 国学
```

22 个板块分三段：**总览 2 块、主题 7 块、用法 13 块**。主题 7 块承载十三部书，按「问题同源」合块（不按书重复）；用法 13 块是全库共用的一份工具，负责把一个知识点推到可交付的成果。

## 库内体例

同一套内容提供三种形态，按需取用：

1. **[`新时代领导干部通识读物系统知识库.md`](<./新时代领导干部通识读物系统知识库.md>)**——**合订本**。22 个板块合在一个文件里（13462 行 / 1.5 MB），适合整体下载、离线通读、一次性导入笔记软件。
2. **`系统知识库/`**——**分板块版**。按合订本的一级标题逐块拆开，共 23 个文件（含 `00_README_总览.md` 导览），内容与原文件逐行一致。单文件最大约 228 KB（板块6），适合按主题独立查阅、版本比对与在线预览。
3. **`读书笔记/`**——**原典笔记**。十三部所据原著的逐本笔记，是上面两层内容的素材来源。

编号与写法约定：

```text
# 板块N · 名称          ← 一级标题，N 取 0~21
## N_x 小节标题          ← 二级标题，x 为该板块内序号（如 0_1、6_27）
```

- 板块编号稳定，跨文件引用一律写「板块N」，配合 `N_x` 小节号可直接定位；
- 每个板块由主旨与结构、方法与工具、案例与落地、校验与纠偏四类内容组成，主题板块末节为收束节（用法 / 动作 / 自查）；
- 案例故事统一四段式：场景 → 转折 → 拆解 → 可迁移，转折写成「什么条件变了」；
- 并列与对照一律用表格，流程与层级一律用 ASCII 图，不依赖任何外链图片；
- 不写死年份，进度用「第 N 周 / 第 N 天」表述；全文 UTF-8，无 HTML 标签。

所据原书（PDF/EPUB 等）不在本仓库内，本仓库仅收录整理笔记与知识库。
