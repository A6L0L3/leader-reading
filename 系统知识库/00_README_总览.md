# 领导干部通识知识体系·十三课贯通手册
## README · 总览

### 这是什么

这是一套把十三部通识著作重构而成的知识体系，不是十三份摘要的合订本。

十三部著作原本各自独立成书，逐本读完，得到的往往是十三个互不相干的知识块。这套手册做的是把它们**纵向分成五层、横向打通成网**：每一层回答一类不同的问题，层与层之间互相校验、互相支撑。读一本是一块砖，读一套是一面墙；墙的价值不在砖多，而在砖与砖之间有咬合。

```text
  第五层  素养层 ── 我怎么表达、怎么识人
            写作 · 美学 · 音乐 · 心理学
                 ▲
  第四层  安全层 ── 我怎么防
            中国古代军事
                 ▲
  第三层  治理层 ── 我怎么干
            法治 · 群书治要
                 ▲
  第二层  思维层 ── 我怎么想
            中国哲学 · 马哲 · 马恩经典 · 逻辑学
                 ▲
  第一层  根基层 ── 我从哪里来
            中华文化 · 国学
```

**它不是什么，同样重要**。它不是名著导读——导读关心"这本书讲了什么"，这套体系关心"这个问题该用哪本书的哪件工具"；它不是考点汇编——汇编追求覆盖，体系追求连通；它也不是一套观点正确的标准答案——十三部书里有相互不完全一致的地方，这些不一致被保留下来，用作跨层校验的材料，而不是被抹平成一句笼统的共识。

**为什么是十三部，而不是更多或更少**。这十三部书的共同点是：每一部都对应领导干部知识结构里一个不可替代的位置。删掉任何一部，体系都会出现一个具体的空洞（板块1会逐一列出这些空洞）；再加若干部，边际收益迅速下降，因为新增的书多半是在同一位置上做补充，而不是开辟新位置。选书的标准是"位置不重复"，不是"内容够全"。

五层的顺序不是随意排的。根基层在下面，是因为文化底色决定你提问的方式——同一桩社会矛盾，从"礼俗秩序"出发与从"契约关系"出发，看到的症结完全不同。思维层在中间，是因为它是唯一能跨领域迁移的部分：法治要用法治思维，军事要用战略思维，二者共享的是同一套分析与判别能力。安全层与治理层并列，二者是一对张力——治理讲建设，安全讲底线，只讲建设容易失去底线，只讲底线容易失去活力。素养层在上面，是因为它不直接产生决策，却决定了决策能否被人理解、能否落地。

### 二十二块的编排逻辑

全书共二十二个板块，分三段：**总览两块、主题七块、用法十三块**。主题七块承载十三部书，用法十三块把一个知识点推到可交付的成果。

| 区段 | 板块 | 作用 |
| --- | --- | --- |
| 总览 | 0、1 | 学习路径建议、知识体系全景图 |
| 根基层 | 2 | 中华文化与国学的底色，两部书合一块 |
| 思维层 | 3、4、5 | 中国哲学的政治智慧、马哲十二思维、马恩经典与逻辑工具 |
| 治理层与安全层 | 6 | 法治、群书治要、古代军事三部书合一块 |
| 素养层 | 7、8 | 写作与审美、音乐修养与心理学 |
| 贯通应用层 | 9、10 | 贯通案例集、落地实操清单 |
| 记录与检索层 | 11、12、13 | 场景应用表、笔记方法与记录模板、分场景记录细则 |
| 答疑与辨析层 | 14、15 | 高频疑问问答、易混概念辨析表 |
| 演练与验证层 | 16、17、18 | 实战演练题、方法失效边界、实用验证体系 |
| 纠偏与收束层 | 19、20 | 常见误读与纠偏、延伸连接与速查卡 |
| 方案层 | 21 | 常见工作场景的成套方案 |

**板块6同时承载治理层与安全层**。三部书里，法治讲权力如何被约束、权利如何被保障，群书治要讲传统治理资源中哪些仍可用，二者是"建设"的一面；古代军事讲战略决策与风险演化，是"底线"的一面。两层的张力收在同一个板块里，读时按"建设—底线"两段推进，不要跳着读，否则张力就看不见了。

**板块2、5、6、7、8都是多书合块**。合块的依据不是篇幅相当，而是问题同源：中华文化与国学同答"依据在哪"，马恩经典与逻辑学同答"结论凭什么成立"，写作与美学同答"判断如何被表达与感知"。合块之后，同一层里两本书的分工反而更清楚，因为比较是在块内完成的。

**板块9到21是用法层**，与前面的主题层不是"正文与附录"的关系。主题层解决"知道什么"，用法层解决"拿去干什么"：板块9给跨层协同的完整样本，板块10把知识压成动作清单，板块11、13解决"遇到场景怎么查、看到东西怎么记"，板块12给记录模板，板块14、15清障，板块16、17、18负责练、划边界、验结果，板块19、20纠偏收束，板块21把一整类工作做成可照着走的成套方案。**板块21是最后一块内容板块**，它给出的是完整成套方案——适用条件、分步骤操作、用到的全套工具、检验标准与常见卡点，照着做完就能交付一个成果。

用法层这十三块本身也有次序，可以按"取—记—问—辨—练—验—纠—连—用"九个动作记：取（11）、记（12、13）、问（14）、辨（15）、练（16）、验（18）、纠（19）、连（20）、用（21），板块9、10、17分别承担示范、清单与边界三种穿插功能。这套次序不是阅读顺序，而是调用顺序——真正卡在哪一步，就翻哪一块，不必从头走。

**板块之间的引用一律用"板块N"的写法**，N 落在 0 到 21 之间。这样写的好处是：任何一处提到别处，读者都能立刻定位，不需要记住章节标题；反过来，如果你在笔记里也照这个格式写引用，半年后回看仍然找得到。

### 每块的统一结构

每个板块由若干二级小节组成（编号形如 `0_1`、`1_2`），一律包含四类内容。

| 类别 | 说明 |
| --- | --- |
| 主旨与结构 | 一句话主旨、结构图、作者的问题意识、关键术语 |
| 方法与工具 | 可命名的思维工具、流程图、对照表、操作模板 |
| 案例与落地 | 四段式案例故事、行动清单、场景表 |
| 校验与纠偏 | 常见偏差自查、误读纠偏、失效边界、验证表 |

**案例故事统一走四段结构**：场景（交代背景与初始状态，具体到能看见画面）→ 转折（交代转折由什么条件变化触发）→ 拆解（说明机制、成立条件与失效情形）→ 可迁移（触发条件加分步骤）。转折一律写成"什么条件变了"，不写"后来他想通了"——因为多数转折不是因为某个人变了，而是因为某个条件变了。

**表格优先于长段叙述**。凡是并列关系、对照关系、判断标准，一律用表；凡是流程、层级、因果，一律用图。这样做的目的不是好看，而是让同一块内容既能通读、又能检索：通读时看段落，检索时看表头。

**小节编号是定位器，不是装饰**。`0_1` 表示板块0的第1节，`6_27` 表示板块6的第27节。编号稳定，引用才稳定；因此小节标题一经确定就不轻易改动，插入新内容时宁可把相邻两节合写，也不重排编号。

**每个主题板块的末节都是收束节**，统一交代三件事：这一层的用法（什么问题该来这里取工具）、这一层的动作（读完能立刻做的两三件事）、这一层的自查（哪些信号说明你没读进去）。跳过末节只读中间，等于拿走零件不留图纸，用的时候装不回去。

### 建议的三种用法

**用法一：系统通读**，适合新任岗位、需要补齐全局视野。按板块0给出的顺序与进度盒走完，产出一张自己的知识体系图和一份验证记录。

**用法二：问题检索**，适合遇到具体问题的时候。先判断问题属于哪一层，翻该层板块，用板块11的场景表定位，取工具，做板块16的演练。这套手册的设计优先照顾这种用法。

**用法三：专题深钻**，适合要在某一领域讲清楚的时候。选定主题后跨层抽取，例如"如何做一项政策的风险评估"，要用到板块6（风险分类与程序正当）、板块4（底线思维）、板块5（论证检验）、板块8（群体心理与危机沟通）。

三种用法里，用法二的使用频率最高。第一次通读时不必精读工具板块，扫一遍知道它们在哪即可；真正需要时再回来细看，效率会高得多。

**用法二有四步，缺一步就会退化成"翻书"**：第一步判断层位（我要的是依据、判断、动作、底线还是表达）；第二步在该层板块里找可命名的工具，而不是找结论；第三步用相邻层校验一次，问"这个结论换个角度看还站得住吗"；第四步把工具用进一个真实场景，并当场记下结果。四步走完，才算真正检索过；只做前两步，得到的是"我好像看过"。

**三种用法可以叠加，但不要同时启动**。同一周里既想系统通读、又想专题深钻，结果通常是两头都浅。合理的排法是：先用一个月走通通读的主干，之后以检索为主，遇到需要对外讲的题目再切到深钻。

### 阅读顺序的三条硬建议

**第一，逻辑要早装。** 板块5里的逻辑学部分排在主体内容之前读完，因为通识阅读最大的风险不是读得少，而是读得多却无法辨别。过滤器越早装上，后面每块的净收益越高。

**第二，原典要后置。** 板块5里的马恩经典精读部分门槛最高，且需要一定的问题意识才读得进去。先读通识再读原典，是带着问题去求证；反过来往往变成死记硬背。

**第三，校验不能省。** 每读完一层，强制自己找一次交叉校验——用这一层的结论去检验上一层的某个说法。这件事没有可见产出，最容易被跳过，却恰恰是把十三块变成一张网的关键。

三条建议的顺序不能颠倒。逻辑最轻，先装；原典最重，后置；校验最"无用"，所以要在过程中反复做。三者合起来是一个配比问题：先用少量时间装判别标准，再用大量时间读主体，中间穿插校验。**如果只允许保留一条**，保留第三条——判别标准可以在别处补，原典可以将来再读，但"用一层检验另一层"的习惯一旦不建立，这套手册就永远只是一套读物。

### 格式说明

+ 总体概览（本文件）加二十二块内容，各一个独立的纯 Markdown 源文件，可直接导入语雀、Typora、Obsidian 等工具。
+ 所有图示均以 ASCII 代码块呈现，无需图片依赖，任何 Markdown 环境都能正常显示。
+ 不含 HTML 标签，不含外部引用标记，不含截断式省略，全文为完整表述。
+ 不出现具体年份，进度一律用"第 N 周""第 N 天"表述，历史年代用朝代表述。
+ 文件编码为 UTF-8。

从这里往下，板块0给出具体的学习路径、进度安排与读法建议。若你已确定自己的问题类型，也可以直接翻到对应层的板块。
